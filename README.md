# 卡珊德拉的哀歌 · Cassandra's Lament

> **命名口径**：对外发布用正式名 **卡珊德拉的哀歌／Cassandra's Lament**；
> **内部代号「远见」（YuanJian）**——日常对话、代码、目录、以及程序界面里的
> 窗口与托盘菜单，一律沿用「远见」。两者指的是同一个程序，不是两个产品。
> 当前版本 **v1.5.3**。

远见是一个只在 Windows 本机运行的外部认知雷达。它持续读取公开信息，把同一事件的多篇报道合并，区分单源线索与多源证据，生成结构化判断，再在本机映射到个人利益和候选预测。

## 运行环境

- 操作系统：Windows 10 或 Windows 11（x64）。
- 界面运行时：**Microsoft Edge WebView2 Runtime 必须已安装**。Windows 11 和已更新的 Windows 10 通常自带；缺失或损坏时程序会明确报错，不会静默退回默认浏览器。
- 源码运行需要 Python 3.13 或更高版本（打包基线为 3.14）。
- 第三方依赖（打包脚本会自动安装，版本固定）：
  - `pyinstaller==6.21.0`
  - `pywebview==6.2.1`
  - `pystray==0.19.5`
  - `Pillow==12.3.0`
- 无需联网即可使用本地研判、利益映射和预测账本；外部 AI 是可选增强项，默认关闭。
- 运行数据统一存放在 `%LOCALAPPDATA%\YuanJian`，不在源码目录或安装目录内。需要换到别的盘时，在 `YuanJian.exe` 旁边放一个 `data-dir.txt`，内容写目标目录即可（例如 `D:\远见\数据`）；环境变量 `YUANJIAN_DATA_DIR` 优先级更高，便于脚本化启动。

## 核心能力

- 主导航：行动首页、**全球态势**（全球事件地图）、告诉远见与设置。个人输入一步可达，原始新闻不占据一级入口。
- 首次打开自动显示三步教程；设置中可以随时重新打开。
- 行动首页只呈现最多 3 条个人事项，先给大致行动建议，再给原因、期限和**关注度**（重点关注 / 需要关注 / 低优先）。
- “告诉远见”允许用一句话记录发生的事或自己的行为，保存后直接返回行动建议和中文关注度。
- **关注度 ≠ 风险量级**：档位由「证据 × 我在乎 × 领域相关 × 紧迫 × **结构强度**」算出（**不再含“置信”**——它与“证据”同由来源数决定，等于同一个变量计两次），其中两项衡量的是与你有多相关。事件**量级**单独给出：证据里有金额/数量就列出来，**没有就写“未量化”**，不用看起来严重的词替代没有的数字。
- **「立即行动」现在必须真有结构性摩擦**：四项分数过线之外，还要求「执行层延误风险为中/高」或命中风险信号才保留 L4——**只有单一来源的事项无论多重要都不得超过 L3**，这条封顶没动。判级用的是程序本来就在算、此前只展示不参与打分的**权力结构判定**（按最低纳入层判执行阻力，不是按发文机关）。判级不再只看「这件事属于哪一类」，而要看「这件事在落地那一层有没有阻力」；结构信号缺失时不降分，但也进不了 L4。
- **全球态势图层**：把三个无需密钥的官方源（**USGS 地震 / NASA EONET 自然事件 / GDACS 灾害告警**，均为 T1 一手源）接成一张可缩放拖拽的世界地图（`#/atlas`），底图为随包投放的公有领域轮廓数据，**无地图库、无在线瓦片、无 CDN**；支持图层开关、时间窗（24 小时 / 72 小时 / 7 天）、点选详情与**数据新鲜度**显示。**这批数据与研判链物理隔离**：独立存储、不进聚类、不进 AI 研判、不产生通知——否则一天两三百条地震会同时炸掉成本与信噪比。量级**不跨图层比较**（地震是震级、火山是 VEI、风暴是风速）。事件保留 30 天后清理。
- **外观**：密教风格主题层（直角、哑光、黄铜为唯一主色，L4 保留唯一强刺激的血红）。零外部依赖：不加载任何网络字体或图片，纸纹与箭头都用内联 `data:` 矢量；图标与文案符号一并统一。**只换外观，不改行为。**
- L1/L2、未完成研判和未命中个人利益的外部信息留在后台，不把分析工作转交给用户。
- 新闻、因果链、反证和来源链接默认折叠在“为什么这样判断”中。
- 情报后台默认只显示处理量、来源覆盖和待核实数量；原始新闻、来源和规则按需加载。
- 事件、外部信息和通知仍使用后端分页，避免一次渲染全部历史。
- 历史与新增 RSS/网页标题、摘要统一转为可见纯文本，脚本、样式、标签和 HTML 实体不会直接出现在界面。
- 通知支持单条已读、全部已读和打开关联风险。

- RSS/Atom、GDELT JSON、公开网页列表、**GeoJSON 点位源**采集；失败状态与指数退避（15/30/60/120/240/360 分钟，成功即归零）可见。
- 72小时事件聚类；中文、英文、数字、金额、比例和日期参与相似度计算。
- **同一件事的后续报道不会被 72 小时切断**：超过 72 小时的**近重复**（高度相似，或有共同数字且相似度很高）仍合并为同一事件，最长到 30 天，合并原因记为「势头延续」可追溯；不是近重复的照旧分开，超过 30 天一律不合并。
- 独立域名与本地标记的官方来源形成 E1—E4 证据等级，同域转载不冒充互证，**跨域全文转载也只算一个声音**（同一内容哈希出现在多个域名时只计 1）；事件详情页会写明「本事件 N 个来源中 M 个为同文转载」。
- 6小时、24小时、7天、30天趋势；历史不足或样本少时不制造“升温”结论。上升阈值按**本轮比较次数**做多重比较校正（不再用固定倍数），并在诊断面板给出 rising 占可判定快照的比例——**超过 20% 即判定阈值失效**。
- 断网可用的本地研判，输出事实、参与者、因果链、不确定性、时间窗和反证触发器。
- **权力结构判定按“执行层”而不是“发文机关”**：一件由国务院发文、但要求各市水务局落实的事，执行阻力判「高」——发文方级别高不等于落得下去。判定会同时给出识别到的机构名与判读依据，判错时你能看得见。
- 「慷慨激昂 = 内心已感知风险」这条规则**上调的是关注度**，不是“系统更有把握”；命中的词会显示出来，不作为黑箱。
- **认知框架是假设，不是事实**：九套观察框架以「候选假设」身份注入，每条都带状态（已验证/未验证）与「主要限制或反证方向」，并要求以证据为准、不得为迎合假设裁剪证据。天外实体侧只在相关事件上注入，不作默认透镜。
- 可选 OpenAI Responses API 严格结构化输出；默认关闭，无密钥、认证失败、限流、超时或非法输出时退回本地。
- 私人利益只在本机映射。E1 无论多重要都不得超过 L3。
- 预测账本的每一条都标明来源：**这一条是你自己选的概率，还是系统自动填的**。自动填入只对 E2 及以上的多源证据生效；E1 单源线索无论多重要，都必须由本人确认才能进入账本。结算方式也标明（逐条判定 / 批量或自动归档）——批量写出来的「无法判定」是“没来得及看”，逐条判定的才是“看了但判不了”。
- **预测闭环真的能转起来**：结算可以按类别与到期区间**一次处理一批**（界面先预览「将结算 N 条、结果 X、影响到期区间 Y」）。批量结算的默认结果是「**无法判定**」——它只清积压，不参与命中率与 Brier；**绝不会**默认成“未发生”，那等于凭空给成百上千条命题盖上没有观察支撑的断言。也可以选择开启「到期满 N 天后自动归档」，**默认关闭**：写进账本的归档不可撤销，这个决定只能由你做。
- 校准面板把每个数字的来源写清楚：命中率 / 误报率 / Brier **只统计你自己选过概率的预测**，系统自动确认的单独分列、不合并；被排除的条目按原因分解（缺可观测事实 / 缺基准率 / 含不可结算表述），并直说「**v1.3 之前的命题补结算也进不了校准**」。
- **命题必须能被一条未来新闻判定**：可观测信号要指向本事件的具体机构、地点或数字（否则停在“待补充”，候选卡上直接标出原因）；结算只认一条**主信号**，且要求它在窗口期内**首次**被观测到——窗口开始前就已成立的事实记为“窗口开始时已成立”，不算命中。
- 账本行**不可删除**（只有 `open → resolved/void` 这一种流转），并带自己的创建时间列；时间轴不再只存在于渲染出来的文本里。
- 诊断面板显示**证据等级分布**，并在没标记过任何官方来源时直说 E3/E4 不可达（当前证据体系实际只有 E1/E2 两级，最窄概率区间用不上）——不替用户标记来源。
- 单实例后台、登录启动选项、运行状态和本地通知中心；系统通知有节流纪律——**同一事件 6 小时硬下限**（不足 6 小时只有告警等级升高才再弹），**6–24 小时需实质性提升**（证据等级上升 / 独立来源变多 / 行动窗口跨档）才提前提醒，**每天最多 6 条系统弹窗**（滚动 24 小时；超出后只进本地通知中心，不丢信息）。
- pywebview 原生桌面窗口与系统托盘；关闭窗口即安全退出（停后台监控、释放端口、退出进程），托盘菜单也可选择显示、运行认知、暂停监控或退出。
- “立即更新判断”显示实时忙碌状态、耗时以及本次处理、研判、利益影响和提醒数量。
- 所有保存、刷新和反馈操作使用可见的忙碌、成功和失败状态，不再依赖阻塞式提示框。
- 只读索引 Obsidian；不写回原文章库。

## 安全边界

程序只监听 `127.0.0.1`。运行数据保存在 `%LOCALAPPDATA%\YuanJian`，不放在源码或安装目录。

程序界面在 Microsoft Edge WebView2 中显示，不会再用默认浏览器打开。只有点击外部公开证据链接时，才会打开系统浏览器。WebView2 缺失或损坏时程序会明确报错，不会静默退回浏览器。

外部 AI 最多接收8个公开来源和12,000字符，只包含公开标题、摘要、网址、域名、时间和通用类别。精确地址、生日、家庭关系、医疗、债务、账户、Obsidian原文、私人利益图和预测历史不得外发。API 密钥使用 Windows 当前用户 DPAPI 加密，不写数据库、日志或源码。

软件不会自动借贷、投资、发送外部消息，或替用户作医疗、法律决定。采集不绕过 TLS、登录、付费墙或反爬。

## 变更记录要点

- **v1.5.0（2026-09-20）**：**把「判定」接回方法论，并新增一层全球态势图层。** 原先是「通知重复」的表面问题，修完通知链路后用户仍觉得 L4 太多——真因在判级：四项加权里「重要度」取自利益对象的预设分值（用户 7 个全是 3 分 ⇒ 恒为 0.6），涉及面是写死的对照表，紧急度是关键词匹配，于是**只有来源数随事件变化**，同类事件分数几乎恒定 `0.68125`，而门槛是 0.68 —— 只高 0.00125。**它判断的不是「这件事重不重要」，而是「这件事属于哪一类」。** 修法是用程序本来就在算、却只展示不参与打分的**权力结构判定**来定级：L4 必须存在执行层摩擦；`importance` 改为「利益预设 × 事件侧结构强度」；结构信号缺失时不降分、但也进不了 L4。真人库实测：最近 24 小时 L4 **68 → 6 条**、涉及事件 22 → **4 个**，每日汇总 7 天内 **8437 → 4515**。同期交付：远程研判补算权力结构（否则花额度换来的升级版会被系统性降级）、存量 11.9 万行一次性回填（迁移 v7，先备份、可重入）、密教主题（只换外观）、全球态势图层（三个无密钥官方源，与研判链物理隔离）、GDELT 指数退避、天外实体触发词收紧（旧词表在真库 79,800 个事件簇上命中 630 条，**真相关 0 条**）。完整说明见 [`CHANGELOG.md`](CHANGELOG.md)。
- **v1.4.1（2026-09-19）**：**对外改名** —— 项目正式名改为 **卡珊德拉的哀歌／Cassandra's Lament**，GitHub 仓库同步改名（地址里写成 `Cassandras-Lament`，因为 GitHub 不允许空格与撇号）。**程序本身一点没动**：窗口标题、托盘菜单、包名、目录、数据目录仍叫「远见」，我们的对话里也仍叫远见；只有对外发布用正式名。旧地址由 GitHub 自动跳转，已经装好的旧版本不会因此失联。
- **v1.4（2026-09-18）**：让「预测 → 结算 → 校准 → 修正」这条闭环**第一次真正跑起来**，并清掉三轮审计确认的失真源。起点是账本 **8,607 条预测、0 条结算**——开环不是使用者的疏忽，而是结算被设计成“逐条三次交互”而生成速度是每天 391 条，**这是吞吐量问题**。四批：① **闭环通电**（批量结算，默认结果为「无法判定」；到期自动归档，默认关闭；校准面板不再把机制问题说成“再等等就好”）；② **分数只量人**（命中率/误报率/Brier 与基准率只统计你自己选过概率的预测；关注度分数去掉与来源数共线的置信项，阈值按真库分布重定）；③ **证伪性闸从“形状”变成“实质”**（删掉两项恒真检查、禁用词不再误伤新闻标题、可观测信号必须事件级特化、结算改为主信号 + 窗口内首次观测）；④ **失真源**（跨域同文只算一个声音、趋势阈值做多重比较校正、账本补不可删保护与创建时间、不再为 L1/L2 生成候选）。全量 **673 项测试连跑三轮全绿**，**15 条变异对照全部“有牙”**。完整说明见 [`CHANGELOG.md`](CHANGELOG.md)。
- **v1.1（2026-09-16）**：一轮独立审计后的修复，四组。
  ① **隐私边界**：此前远程研判会把个人近况、利益对象与关系、预测历史一并发送给所配置的
  AI 服务，与 `PRIVACY.md` 的承诺冲突。现在远程请求**只含公开证据包**，并有队列侧剥离与
  provider 出口剥离两道独立防线；本机个性化不受影响。
  ② **数据完整性**：「判读不可变 / 预测账本不可变」此前并未真正强制 —— `INSERT OR REPLACE`
  可绕过触发器（默认配置下 REPLACE 的冲突消解不触发删除触发器），且 `resolutions`
  完全没有触发器。均已修复。
  ③ **数据安全**：备份保留已静默退化（承诺 7 份、实际 3 份，且诊断面板指向一份旧空壳）；
  已修复，且保留份数现在**可由用户自行调整**。
  ④ **设置真正可改**：修了四处「值存进去但不生效」的缺陷，其中「改备份时段会把备份开关
  悄悄关掉」后果最重。另「立即备份」按钮此前是空壳，现在真的会备份。
- **v1.1**：外部 AI 的**每日上限可配置**（默认 2000，原写死 100），并新增**请求速率闸**
  （两次请求至少间隔 5 秒）—— 放开配额后实测撞了服务商限流，13% 的请求被拒且退避过长，
  净吞吐反被压住。被限流的退避同时从 15 分钟缩短到 1/2/4 分钟。
- 2026-09-13：修复 E1 证据等级的上限。此前 `_alert_level()` 只按分数分档，E1 可以算到 L4；而 `map_judgment()` 会对 L4 候选自动确认，等于单一来源线索未经人工选择概率就写入不可变预测账本。现已在 `impacts.py` 强制 E1 不得超过 L3。**注：该次修复后来被发现并未真正生效** —— 自动确认只筛告警级别、不看证据等级，E1 降到 L3 后照样被自动确认；已在 v1.1 补上证据等级闸（E1 一律不得自动确认），并让账本标明每条的来源是人类选择还是机器填入。完整测试套件在该次改动时全部通过。
